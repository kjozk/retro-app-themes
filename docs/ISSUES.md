## 課題詳細

### ISSUE-001: テーマ一覧で世代順で並ばない

* **ステータス**: Resolved (解決済み)
* **優先度**: 中 (UI/UX 改善)
* **対応方針**: 案 A（発売年代・西暦プレフィックス `[YYYY]` 導入）を採用して反映完了
* **対象コンポーネント**: 
  - OBS Studio テーマメタデータ (`.ovt` の `@OBSThemeMeta.name`)
  - Zed エディタテーマ定義 (`.json` の `name`)
  - 各種 README およびインストーラーのテーマ選択一覧

#### 1. 現象と課題の概要
OBS Studio の設定ダイアログ（「設定」→「外観」→「テーマ」）や Zed エディタのテーマ選択パレット（`theme: select`）において、収録テーマが **ハードウェアや OS の発売年代（世代順）に並ばず、アルファベット順でソートされてしまう** ため、歴史的変遷や世代ごとのテーマ選択が直感的に行いにくい。

#### 2. 原因分析
OBS Studio および Zed のテーマセレクターは、メタデータに定義されたテーマ表示名（`name`）の文字列をキーとして自動ソート（昇順ソート）します。
現在設定されている英語略称・プレフィックスでは、以下のように世代順とアルファベット順に食い違いが生じています：

| 世代 / 年代 | ハードウェア / OS | 現在の OBS 表示名 | アルファベット順位置 | 課題（並び順の狂い） |
| :---: | :--- | :--- | :---: | :--- |
| **1983 (第3世代)** | ファミリーコンピュータ | `FC - ファミリーコンピュータ` | 1 | 正常 |
| **1985 (海外第3世代)** | NES | `NES - Nintendo Entertainment System` | 3 | 本来は GB (1989) より前であるべき |
| **1989 (携帯機)** | ゲームボーイ | `GB - ゲームボーイ` | 2 | NES より先に来てしまう |
| **1990 (第4世代)** | スーパーファミコン | `SFC - スーパーファミコン` | 4 | 正常 |
| **1991 (海外第4世代)** | SNES | `SNES - Super Nintendo Entertainment System` | 5 | 正常 |
| **1995〜2000** | Windows Classic | `Windows Classic` | 9 | Windows XP より先に来るが末尾に近い |
| **2001** | Windows XP Luna | `Windows XP Luna` | 10 | 末尾 |
| **2006 (第7世代)** | Nintendo Wii | `Wii - Nintendo Wii` | 8 | **Switch (2017) より後ろに並んでしまう** (W > S) |
| **2017 (第8世代)** | Nintendo Switch | `Switch Dark` / `Switch Light` | 6, 7 | **Wii (2006) より前に並んでしまう** (S < W) |

特に、**2006年発売の Wii (`W`) が 2017年発売の Switch (`S`) よりも後に配置される問題** や、携帯機と据置機の年代順の前後関係が崩れている点が顕著です。

#### 3. 解決策・改修案の検討
ユーザー体験とテーマの可読性を損なわずに、世代順のソートを実現するための候補案：

- **案 A: 発売年代（西暦）プレフィックスの導入（推奨）**
  - 例: `[1983] FC - ファミリーコンピュータ`
  - 例: `[1985] NES - Nintendo Entertainment System`
  - 例: `[1989] GB - ゲームボーイ`
  - 例: `[1990] SFC - スーパーファミコン`
  - 例: `[1991] SNES - Super Nintendo Entertainment System`
  - 例: `[1995] Windows Classic (95/98/2000)`
  - 例: `[2001] Windows XP Luna`
  - 例: `[2006] Wii - Nintendo Wii`
  - 例: `[2017] Switch Dark` / `[2017] Switch Light`
  - *メリット*: アルファベット順ソートの仕様下でも、西暦数値によって自然に 100% 正確な世代順ソートが実現できる。レトロテーマとしての歴史的コレクション価値も直感的に伝わる。

- **案 B: 世代番号プレフィックスの導入**
  - 例: `[Gen3] FC - ...`, `[Gen4] SFC - ...`, `[Gen7] Wii - ...`, `[Gen8] Switch - ...`
  - *デメリット*: Windows Classic や Windows XP といった OS テーマとの記法統一が難しくなる。

- **案 C: カテゴリ連番プレフィックスの導入**
  - 例: `01. FC`, `02. NES`, `03. GB`, `04. SFC`, `05. SNES`, `06. Wii`, `07. Switch ...`
  - *メリット*: 完全な順序制御が可能。

#### 4. 対応内容と結果
案 A（発売年代・西暦プレフィックス `[YYYY]`）を採用し、以下の対応を実施完了：
1. **OBS テーマメタデータ (`obs-studio/themes/*.ovt`)**: 全 10 テーマの `name` を `[1983]`〜`[2017]` で更新。
2. **Zed テーマ定義 (`zed/themes/*.json`)**: 全 7 JSON（計 28 バリアント）の各テーマ `name` を西暦プレフィックス付きへ更新。
3. **インストーラー (`install.ps1`, `install.sh`)**: 適用方法メッセージのテーマ選択肢を西暦世代順に更新。
4. **ドキュメント (`obs-studio/README.md`, `zed/README.md`)**: テーマ適用手順の選択肢を西暦世代順に同期。
5. **動作検証**: OBS および Zed のソート仕様下で、1983年（FC）から 2017年（Switch）まで完全な世代順・時系列順に整列することを確認済み。
