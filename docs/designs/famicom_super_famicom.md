# ファミリーコンピュータ & スーパーファミコン テーマ詳細設計書

日本の家庭用ゲーム機を代表するファミリーコンピュータ（1983年）およびスーパーファミコン（1990年）の実機成型色、金属プレート、およびボタン配色を忠実に再現したテーマ設計書です。

---

## 1. ファミリーコンピュータ (Family Computer)

### カラーパレット定義
| 変数名 | カラーコード | 実機パーツ / マテリアル | UI マッピング |
| :--- | :--- | :--- | :--- |
| `--fc_body` | `#F7F6F2` | 本体アイボリーホワイト成型色 | ウィンドウ・ダイアログベース背景 |
| `--fc_body_dark` | `#EDEAE1` | 陰影部のアイボリー成型色 | リスト・サイドバー背景 |
| `--fc_red` | `#98161F` | 伝統のえんじ色（Maroon プラスチック） | ドックヘッダー、配信ボタン、決定 (OK) ボタン |
| `--fc_gold` | `#CEA56B` | コントローラー前面の真鍮・金ヘアラインプレート | 録画ボタン、フォーカスハイライト、アクセント |
| `--fc_black` | `#1A1A1C` | 十字キー・ゴムボタン（Matte Black） | コントロール補助、通常文字色 |
| `--bg_preview` | `#221F1A` | 引き締まったダークウォームグレー | プレビュー周囲背景 |

### UI メタファー適用ルール
1. **えんじ色 × 金プレートの象徴的対比**:
   - 配信（Stream）を本体色の象徴である「えんじ色（`#98161F`）」、録画（Record）をコントローラーの象徴である「金プレート（`#CEA56B`）」にマッピング。
2. **文字色の白飛び・コントラスト保護**:
   - アイボリー背景上の文字色は `#1A1A1C`（ウォームブラック）を徹底し、えんじ色面の上には純白（`#FFFFFF`）を適用（コントラスト比 7.0:1 以上）。

## 2. スーパーファミコン (Super Famicom)

### カラーパレット定義
| 変数名 | カラーコード | 実機パーツ / マテリアル | UI マッピング |
| :--- | :--- | :--- | :--- |
| `--sfc_body` | `#D8DCE2` | 本体ライトグレー成型色 | ウィンドウベース背景 |
| `--sfc_body_dark` | `#C8CCD4` | カセット周辺・沈んだライトグレー | リスト・サイドバー背景 |
| `--sfc_dark` | `#464A52` | POWER / RESET スイッチ・十字キー | コントロールボタングループ通常色 |
| `--sfc_blue` | `#005EC4` | X ボタン（Top）- ロイヤルブルー | 配信ボタン、主要フォーカス枠 |
| `--sfc_yellow` | `#F0B400` | B ボタン（Bottom）- 山吹イエロー | 音声ミキサーメーター注意域、録画ボタン |
| `--sfc_green` | `#009E46` | Y ボタン（Left）- エメラルドグリーン | 音声ミキサーメーター正常域、仮想カメラ |
| `--sfc_red` | `#E01E34` | A ボタン（Right）- ヴィヴィッドレッド | スタジオモード、警告・停止表示 |

### UI メタファー適用ルール
1. **ABXY 4色ボタンの機能的割り当て**:
   - 右側（A: 赤）、左側（Y: 緑）、上側（X: 青）、下側（B: 黄）の4色を、OBS のコントロールアクションやエディタのシンタックスハイライトに直感的に分散配置。
2. **ダークスレートスイッチの質感**:
   - 操作ボタンのベースには成型色グレー（`#464A52`）を適用し、ホバー・アクティブ時に4色の発光境界線（Glow）で状態を表現。
