# 機種別詳細設計書インデックス (Hardware & OS Design Specifications)

本ディレクトリ（`docs/designs/`）は、各レトロハードウェア、クラシック OS、およびモダンゲーム機の実機サンプリングカラーコード、マテリアル意匠、UI コンポーネントマッピング等の **機種固有の知見を一元管理** する設計書アーカイブです。

テーマ共通の設計原則・理論体系については、[retro-ui-metaphor-design スキル](../../.agents/skills/retro-ui-metaphor-design/SKILL.md) を参照してください。
