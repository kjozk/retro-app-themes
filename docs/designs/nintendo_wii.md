# Nintendo Wii テーマ詳細設計書

2000年代中盤の Nintendo Wii が提示した、白を基調としたリビング向け家電のような「クリーン＆ミニマル」な実機意匠および低コントラスト色補償ルールの完全仕様です。

---

| :--- | :--- | :--- | :--- |
| `--wii_bg` | `#F4F5F7` | 光沢ホワイトプラスチック成型色 | ウィンドウベース背景 |
| `--wii_card` | `#FFFFFF` | 清潔な純白カード | リスト・入力コンテナ背景 |
| `--wii_cyan` | `#22B2E9` | WiiWare / チャンネル選択枠（アイコニックシアン） | 枠線、ボタン塗り、アイコン、進行状況バー |

## 2. コントラストと可読性の設計ルール（白 × 水色）

白背景の上に明度・彩度の高い水色（`#22B2E9`）を文字色として使用すると、コントラスト比が不足（約 2.44:1）して可読性を著しく損ないます。以下の厳格な役割分担によって実機らしさと視認性を両立させます：

1. **色面・境界としての水色（`#22B2E9`）**:
   - ボタン塗り、枠線（border）、アイコン、プログレスバー、選択行の半透明オーバーレイ（`#22B2E933`）として使用。
2. **水色塗りの上の前景色（反転文字）**:
   - 水色背景の上の文字色には白ではなく、濃紺（`#062A3B`、コントラスト比 6.14:1）を採用し、圧倒的な読みやすさを確保。
3. **水色テキストの代替（スロット LED 濃青 `#136185`）**:
   - 白背景上で「水色系の文字」を表示したい箇所（リンクやフォーカスラベルなど）には、スロット LED の濃青（`#136185`、コントラスト比 6.83:1）を適用。
4. **コントロールボタン枠線 2px 固定の徹底**:
   - 配信・録画・仮想カメラ・スタジオモードなどのコントロールボタンは、通常時・ホバー時・アクティブ時すべてで `border: 2px solid` を固定し、状態変化に伴うレイアウトのブレ（リフロー）を完全に排除。
