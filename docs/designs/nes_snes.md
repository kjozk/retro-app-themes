# NES & SNES (北米版コンソール) テーマ詳細設計書

日本版（ファミコン・スーパーファミコン）と根本的に意匠・成型色が異なる北米版ハードウェア（NES: Nintendo Entertainment System / SNES: Super Nintendo Entertainment System）の実機パレットと機能的マッピング仕様です。

---

## 1. NES (Nintendo Entertainment System)

### カラーパレット定義
| 変数名 | カラーコード | 実機パーツ / マテリアル | UI マッピング |
| :--- | :--- | :--- | :--- |
| `--nes_body_light` | `#DCDAD6` | 本体上部・コントローラー上部（ライトグレー） | ウィンドウ・ダイアログベース背景 |
| `--nes_body_dark` | `#8B8885` | 本体下部・側面成型色（ミディアムグレー） | リスト・サイドバー背景、ドックヘッダー |
| `--nes_black` | `#2E2E2E` | コントローラー外枠・十字キー（マットブラック） | コントロールボタングループ、メイン文字色 |
| `--nes_red` | `#C3222B` | A / B ボタン・Nintendo ロゴ（レーシングレッド） | 配信ボタン、決定 (OK) ボタン、アクセント |
| `--nes_border` | `#5C5A58` | スロットドア・パーツ境界のスモーキーグレー | コンポーネント境界線 |

### UI メタファー適用ルール
- 日本版の「暖色アイボリー × えんじ色 × 金ヘアライン」に対し、NES は「完全な無彩色ベース × 鮮烈なレーシングレッド」のハイコントラスト構成。
- メニューや主要ボタンは赤アクセント、サブ要素はマットブラック・グレーで統一。

---

## 2. SNES (Super Nintendo Entertainment System)

### カラーパレット定義
| 変数名 | カラーコード | 実機パーツ / マテリアル | UI マッピング |
| :--- | :--- | :--- | :--- |
| `--snes_body` | `#D0CED1` | クールグレー成型色（わずかに青・紫みを含む） | ウィンドウベース背景 |
| `--snes_body_dark` | `#B8B4BC` | トレイ周辺・沈んだクールグレー | リスト・サイドバー背景 |
| `--snes_purple` | `#6B3FB5` | POWER / RESET スイッチ、A / B 凸ボタン | 配信・録画ボタン、主要アクセント |
| `--snes_lavender` | `#A99BD8` | X / Y 凹ボタン（淡いラベンダー） | 仮想カメラ・スタジオモード、サブアクション |
| `--snes_dark` | `#3C3844` | 十字キー・背面成型色（ダークバイオレット） | 通常文字色、深い境界線 |

### UI メタファー適用ルール
- 日本版 SFC の「ABXY 4色ボタン」に対し、北米版 SNES は「ディープパープル × ラベンダー」の 2 系統パープルで構成。
  - **主要アクション（配信・録画）**: ディープパープル（`#6B3FB5`）
  - **副次的アクション（仮想カメラ・スタジオモード）**: ラベンダー（`#A99BD8`）
  - **アクティブ時**: 濃色背景 ＋ 相手方の色による発光ボーダーで明快に状態表示。
