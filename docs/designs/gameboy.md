## 2. STN 反射型液晶画面パレット（テトリス実機ピクセル準拠）

小型サブディスプレイとして機能させる情報表示コンテナ（ソースリスト、音声ミキサー、設定入力欄等）に適用する 5 段階の階調パレットです。

| 役割 | カラーコード | RGB 値 | 説明 |
| :--- | :--- | :--- | :--- |
| **ベース液晶背景** | `#8CAD28` | (140, 173, 40) | 未点灯ドットの黄緑液晶色。リスト・入力欄の通常背景。 |
| **最暗ドット前景色** | `#214231` | (33, 66, 49) | 点灯ドットの最暗色。通常テキスト、アイコン、確定枠線。 |
| **ホバー時背景** | `#9EC03E` | (158, 192, 62) | マウスホバー時の明オリーブ。枠線は `#709428`。 |
| **確定選択・フォーカス** | `#BCE248` | (188, 226, 72) | 最高明度のオリーブゴールド。選択テキストは `#214231` を維持。 |
| **無効状態 (Disabled)** | `#6E8620` | (110, 134, 32) | 沈んだオリーブ。文字色は `#3E5020`。 |

## 3. UI メタファー適用ルール

1. **成型色と印字色の分離**:
   - ボタンには成型小豆色（`#8E1E4F`）やラバーグレー（`#9CA0AA`）を割り当て、ロゴ色（`#393C9F`）をボタン成型色としてベタ塗りしない。
   - ロゴ青紫色は枠線や文字刻印、録画トグルなどの機能アクセントとして配置。
2. **ベゼルカバーと液晶画面の二重構造**:
   - プレビュー外周はスレートグレー（`#686E7A`）を配置し、ディスプレイ保護パネルの奥行きを表現。
   - 液晶オリーブ階調は入力フォーム群（`QLineEdit`, `QComboBox`, `QSpinBox`, `QListView`）に一貫して適用。
