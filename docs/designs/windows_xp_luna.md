# Windows XP Luna テーマ詳細設計書

2001年に登場した Windows XP のビジュアルスタイル「Luna（ルナ）」が持つ、プラスチックの光沢、ソフトな立体グラデーション、および鮮やかなアクセントカラーの完全仕様です。

---

## 1. カラーパレット & グラデーション定義

現代の高精細ディスプレイでも黄ばみを感じさせない、クリーンなペールシルバーグレーを基調に調整したパレットです。

| 変数名 | カラーコード | 役割 |
| :--- | :--- | :--- |
| `--xp_bg` | `#EEF1F4` | 清潔感のある明るいペールシルバーグレー（ウィンドウ背景） |
| `--xp_bg_light` | `#FFFFFF` | 入力欄・リストボックスの純白背景 |
| `--xp_bg_dark` | `#DCE0E6` | クラシックベベル・未選択タブ・ステータスバー |
| `--xp_border` | `#7F9DB9` | XP 特有のスカイブルーグレー枠線 (Sunken Border) |
| `--luna_blue_bot` | `#0055EA` | 象徴的ロイヤルブルー（主要アクション、確定ボタン） |
| `--luna_green_mid`| `#389B27` | スタートボタン風エメラルドグリーン（配信・開始） |
| `--luna_red_mid` | `#E83610` | 閉じるボタン風ルナレッド（停止・警告） |
| `--luna_gold` | `#E68B2C` | ホバー時のゴールド光彩ハイライト（`#FFEBB8`） |

---

## 2. スキューモーフィズム質感の設計ルール

1. **ソフトなシルバー白グラデーション**:
   - ボタン通常時は純白からシルバーへの繊細な立体グラデーション（`#FFFFFF` → `#ECE9D8` → `#D8DEE6`）。
2. **ゴールド光彩ホバー**:
   - マウスホバー時にオレンジ〜ゴールドの光彩（`#E68B2C`, `#FFEBB8`）をボーダーに付与。
3. **ロイヤルブルーのフォーカス**:
   - 入力欄や確定ボタン（OK・閉じる）に鮮やかな XP ロイヤルブルー（`#0055EA`）のアクセント。
4. **フォントスタック**:
   - 日本語 UI では `'MS UI Gothic', 'Tahoma', 'Meiryo UI', sans-serif` を最優先に指定し、当時の OS 表示の佇まいを再現。
